### Added

- Video file inspector: drop a file on the window or Dock icon, or press `Command`+`O`
- Tabs per stream kind (General, Video, Audio, Subtitles, Cover Art), only those present in the file
- Thumbnail and cover-art previews
- "On 16:9 TV" row and a 16:9 TV guide on the start screen
- Native window tabs: several files open as tabs, `Command`+`T` for an empty one
- Universal app (Apple Silicon and Intel)
